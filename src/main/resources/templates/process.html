Screen flow

Landing page to publishing workflow

This page documents the intended MVC product flow so we can build the backend and the front-end screens around the same journey.

1. Discovery

Users land on the site, learn the value of the service, and request a consultation or choose a package.

2. Account setup

The purchaser creates an account, connects parent details, and receives OTP verification through email.

3. Project workspace

The dashboard hosts progress tracking, media upload, transcription review, security controls, and draft approval.

4. Delivery

When the memoir is approved, the system supports print output, secure cloud archive, and QR-based access.
