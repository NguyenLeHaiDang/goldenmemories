Screen flow

From consultation to publishing, one clear journey.

The screen flow mirrors the implementation plan so the front end and backend can be built against the same state changes and user expectations.

Journey

The user moves through four simple phases

Each phase should hand off to the next one without forcing the user to guess what to do next.

01 Discovery

Explore the offer

Visitors learn the value of the service and can request a consultation immediately.

02 Identity

Register and verify

The purchaser creates an account, verifies email, and signs in with social login if desired.

03 Workspace

Manage the project

The dashboard, editor, story timeline, and parent profile screen keep the memoir moving.

04 Delivery

Approve and publish

Reviewed drafts are handed off for print, archive, QR access, and final delivery.
