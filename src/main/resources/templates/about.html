About the build

Built as an MVC family-memory platform.

The technical plan focuses on identity, project state, story collection, editing, and publishing. Business storytelling stays out of the implementation path.

Architecture

How the app is structured

Spring Boot controllers route each screen, service layers manage project state, Thymeleaf renders the views, and static CSS/JS controls the user experience.

That keeps the project easy to reason about as we add persistence, authentication, workflow, and publishing screens in sequence.
